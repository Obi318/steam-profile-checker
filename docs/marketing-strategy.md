# Steam Checker Marketing Strategy (Execution Version)

## 1) Core Job To Be Done
Players do not need a cheat verdict. They need fast context after a suspicious death while emotions are high and queue momentum matters.

Steam Checker wins when it answers:
"Does this account look like a normal competitive player profile, or a higher-risk profile?"

## 2) Foundational Persona (Primary ICP)
Primary user:
- Competitive gamer in squad comms (duo/trio/stack).
- Plays games with high-friction deaths and strong skill-cheat ambiguity.
- Experiences suspicious instant-death moments, then immediately seeks evidence.
- Searches phrases like "steam checker", "cs2 cheater check", "is this steam profile legit".

Trigger moment:
- Saturday night, high-intensity session, suspicious wipe, frustration spike.
- Player alt-tabs, searches, needs answer in under 30 seconds.

Decision criterion:
- Fast speed.
- Clear summary.
- Non-accusatory confidence language.
- Shareable output for squad alignment.

## 3) Positioning
Positioning statement:
- Steam Checker is the fastest trust snapshot for suspicious Steam profiles.
- It reads public profile signals and turns them into immediate context.
- It is not anti-cheat software and does not issue definitive cheating verdicts.

Messaging pillars:
1. Speed: "Profile URL in. Trust snapshot out."
2. Context: "Age, bans, library, friends, Steam level, optional game hours."
3. Squad workflow: "Share link instantly in comms."
4. Credibility: "Context tool, not accusation engine."

## 4) Offer Architecture
Top-of-funnel offer:
- Free trust snapshot for any public Steam profile.

Mid-funnel offer:
- Educational guides explaining signal interpretation.

Activation offer:
- Game-specific landing pages that pre-select game context.

## 5) Acquisition System
Channel 1: Search intent
- Publish long-tail pages:
  - `/game/arc-raiders`
  - `/game/counter-strike-2`
  - `/game/call-of-duty`
  - `/game/rust`
  - `/game/the-finals`
- Publish evergreen guides:
  - `/how-trust-score-works`
  - `/steam-vac-ban-context`
  - `/steam-profile-private-vs-public`

Channel 2: Community trust
- Reddit and Discord educational posts on profile signal reading.
- Use guide pages as value-first links; checker CTA is secondary.

Channel 3: Short-form video loop
- Clip structure:
  1) suspicious kill clip
  2) "this felt wrong"
  3) open Steam Checker
  4) show trust snapshot
  5) squad reaction and re-queue decision

Channel 4: Creator mini-series
- "Sus Check Saturday" weekly format.
- Encourage result-link sharing for audience interaction.

## 6) Instrumentation KPIs
Track events now implemented:
- `check_started`
- `check_completed`
- `check_failed`
- `share_completed`
- `share_failed`
- `report_copied`
- `report_copy_failed`
- `landing_attribution`

Primary KPIs:
1. Check completion rate.
2. Share rate per completed check.
3. Landing page to first-check conversion.
4. Organic sessions per guide/game page.

## 7) 14-Day Rollout Plan
Days 1-3:
1. Deploy new pages and sitemap.
2. Submit sitemap in Google Search Console.
3. Publish 3 educational posts using copy bank.

Days 4-7:
1. Launch 5 short-form clips.
2. Test two hook lines per clip.
3. Track which hook yields most `check_completed`.

Days 8-14:
1. Outreach to 20 targeted Discord communities/mods.
2. Start one creator collab pilot.
3. Double down on best-performing game page.
